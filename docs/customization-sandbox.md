# Customization Sandbox System

## Overview

**CraftPires is a creative sandbox** where players can design unique aesthetic civilizations with realistic consequences. Every customization choice has gameplay implications, and hilarious failures create memorable stories shared across social media.

## The Settlers-Inspired Building System

### Physical Material Delivery

**Realistic Construction:**
- **Peasants must physically carry** materials to building sites
- **No instant building** - Materials must be transported and placed
- **Construction phases** - Each stage requires specific materials
- **Tool requirements** - Peasants need appropriate tools for each task

**Material Transport Process:**
1. **Gather materials** - Peasants collect resources from storage
2. **Load transport** - Carts, hovercrafts, or manual carrying
3. **Travel to site** - Physical movement to construction location
4. **Unload materials** - Place resources at building site
5. **Begin construction** - Peasants use tools to build
6. **Repeat** - Each construction phase needs new materials

**The Settlers Experience:**
- **Supply chains** - Materials flow from storage to construction
- **Logistics planning** - Efficient transport routes matter
- **Resource management** - Balance gathering vs construction
- **Peasant coordination** - Multiple workers needed for large projects

## Technical Implementation

### Material System

```typescript
interface DecorativeMaterial {
  id: string;
  type: 'wool' | 'dye' | 'glass' | 'gem';
  color: Color;
  flammability: number; // 0-1, how easily it burns
  durability: number; // 0-1, how long it lasts
  cost: ResourceMap;
  aestheticValue: number; // 0-1, how beautiful it is
}

interface BuildingCustomization {
  buildingId: string;
  baseMaterials: Material[]; // Structural materials
  decorativeMaterials: DecorativeMaterial[]; // Aesthetic materials
  customColors: Color[];
  specialEffects: Effect[];
  fireResistance: number; // Overall fire resistance
  aestheticScore: number; // Overall beauty rating
}
```

### Fire System

```typescript
interface FireSpread {
  source: Position;
  intensity: number;
  spreadRate: number;
  affectedMaterials: Material[];
  damagePerSecond: number;
}

function calculateFireSpread(fire: FireSpread, building: Building): boolean {
  const materials = building.decorativeMaterials;
  const flammability = materials.reduce((sum, mat) => sum + mat.flammability, 0);
  
  if (flammability > fire.intensity) {
    building.catchFire();
    return true;
  }
  
  return false;
}
```

### Peasant Behavior

```typescript
interface PeasantConstruction {
  peasantId: string;
  task: 'gather' | 'transport' | 'build' | 'decorate';
  materials: Material[];
  tools: Tool[];
  destination: Position;
  progress: number;
}

function peasantConstructionAI(peasant: Peasant, task: ConstructionTask) {
  switch (task.type) {
    case 'gather':
      peasant.gatherMaterials(task.materials);
      break;
    case 'transport':
      peasant.carryMaterials(task.materials, task.destination);
      break;
    case 'build':
      peasant.buildStructure(task.blueprint, task.materials);
      break;
    case 'decorate':
      peasant.applyDecorations(task.decorativeMaterials);
      break;
  }
}
```
